サイトの管理

GitHub の Fine-grained personal access token を入力してください。 トークンはこのブラウザの localStorage にのみ保存され、 サイトのコードやリポジトリには含まれません。

  1. GitHub → Settings → Developer settings → Fine-grained tokens で発行
  2. Repository access: sasanoha-tk.github.io のみ
  3. Permissions: Contents = Read and write だけを付与
